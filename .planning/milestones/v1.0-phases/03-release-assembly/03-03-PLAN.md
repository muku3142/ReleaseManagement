<objective>
Put the release lifecycle on HTTP: create, read one, list/search, freeze, delete — plus the three
new `ProblemDetail` reason codes the UI contract depends on.

Purpose: this is the first slice of Phase 3 a human can actually exercise. After it, a release
exists as an addressable resource with a lifecycle; plan 03-04 fills it with tickets and plan
03-05 puts screens on it.

Output: `ReleaseService`, `ReleaseController`, six DTOs, three new exception handlers, and a
`@WebMvcTest` covering every endpoint and every failure mapping.

Scope note (not a scope reduction): `POST /api/releases` in this plan takes name, version and
jiraProjectKey only. Plan 03-04 extends the *same* `CreateReleaseRequest` record with `ticketKeys`
and changes the create response to `ReleaseAddResultResponse`, because the ticket-materialisation
machinery lands there. No consumer exists between wave 3 and wave 4, so nothing is left half-built
at the end of the phase.

```java
@Service
public class ReleaseService {

    private final ReleaseRepository repository;

    public ReleaseService(ReleaseRepository repository) {
        this.repository = repository;
    }

    public Release create(String name, String version, String jiraProjectKey, String actor) {
        Release release = Release.create(name.trim(), version.trim(), blankToNull(jiraProjectKey),
                actor, Instant.now());
        return repository.create(release, List.of());
    }

    public Release get(UUID id) {
        return repository.findById(id).orElseThrow(ReleaseNotFoundException::new);
    }

    public List<ReleaseSummary> search(String query) {
        return repository.search(query == null ? "" : query.trim());
    }

    public Release freeze(UUID id, String actor) {
        // D-03-10: freeze is a one-way door, so freezing an already-frozen release is a
        // conflict, not a no-op - silently succeeding would hide a stale UI.
        get(id).requireOpen();
        return repository.freeze(id, actor, Instant.now());
    }

    public void delete(UUID id) {
        // D-03-11: an OPEN release has no history anyone relies on; a FROZEN one is an audit
        // record and deletion must be refused.
        get(id).requireOpen();
        repository.delete(id);
    }

    private static String blankToNull(String value) {
        return value == null || value.isBlank() ? null : value.trim();
    }
}
```

@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public ReleaseResponse create(@Valid @RequestBody CreateReleaseRequest request, Principal principal) {
    // Every /api/** path is authenticated() in SecurityConfig, so Spring Security guarantees a
    // principal here; its name is the Jira accountId recorded as the actor (D-03-12).
    return toResponse(service.create(request.name(), request.version(), request.jiraProjectKey(),
            principal.getName()));
}

@GetMapping
public ReleaseSearchResponse list(@RequestParam(name = "query", defaultValue = "") String query) {
    return new ReleaseSearchResponse(service.search(query).stream()
            .map(ReleaseController::toSummaryResponse).toList());
}

@GetMapping("/{releaseId}")
public ReleaseResponse get(@PathVariable UUID releaseId) {
    return toResponse(service.get(releaseId));
}

@PostMapping("/{releaseId}/freeze")
public ReleaseResponse freeze(@PathVariable UUID releaseId, Principal principal) {
    return toResponse(service.freeze(releaseId, principal.getName()));
}

@DeleteMapping("/{releaseId}")
@ResponseStatus(HttpStatus.NO_CONTENT)
public void delete(@PathVariable UUID releaseId) {
    service.delete(releaseId);
}
