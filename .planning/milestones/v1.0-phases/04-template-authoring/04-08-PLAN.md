**Unsaved-changes handling.**
- Router navigation: use TanStack Router's navigation blocker (`useBlocker`) gated on `dirty`. When
  it fires, open `ConfirmDialog` with:
  - `title="Discard unsaved changes?"`
  - ``body={`You have unsaved edits to '${template.data.name}'. Leaving now will discard them.`}``
  - `confirmLabel="Discard changes"`,
    `confirmClassName="rounded border border-red-600 px-4 py-2 text-sm font-semibold text-red-600 disabled:opacity-50"`
  - `onCancel` resumes editing. `ConfirmDialog`'s own left button already reads "Cancel"; UI-SPEC's
    "Keep editing" wording would require changing the shared component, so **use "Cancel" and record
    the deviation in the summary** rather than modifying a component three other screens depend on.
- Tab close / reload: a `useEffect` registering a `beforeunload` listener while `dirty` is true:
  ```tsx
  useEffect(() => {
    if (!dirty) return;
    const handler = (e: BeforeUnloadEvent) => { e.preventDefault(); };
    window.addEventListener('beforeunload', handler);
    return () => window.removeEventListener('beforeunload', handler);
  }, [dirty]);
  ```
- Switching to a different template id while dirty is the same case as navigating away, so it is
  covered by the same blocker — no separate handling.
