```java
String token = null; int pages = 0; Map<String, LinkedCommit> bySha = new LinkedHashMap<>();
do {
    if (++pages > maxPagesPerPr) throw new AdoAccessException(AdoFailureReason.TOO_LARGE);
    ResponseEntity<JsonNode> res = getWithOneRetry(uri for page, credential.token());

        c.path("comment").asString(""), c.path("author").path("name").asString(null),
        Instant.parse(c.path("author").path("date").asString()), repository.repositoryWebUrl() + "/commit/" + sha)); }
    token = res.getHeaders().getFirst("x-ms-continuationtoken");
} while (token != null && !token.isBlank());
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-32 | Information disclosure / SSRF | AdoRestAdapter.pullRequestCommits | mitigate | Host is the configured base URL; org from `AdoRepoRef` (host pinned to dev.azure.com, org regex), repository GUID and numeric PR id regex-checked before any call; all path parts are encoded template variables; the payload `url` is never requested |
| T-06-33 | Information disclosure | PAT handling | mitigate | Credential read once per run on the request thread; token never logged or put in exception messages (reason names only) |
| T-06-34 | Denial of service | ADO budget | mitigate | Adapter-wide Retry-After gate, one retry on 429, page ceiling 5 x 100, run-level PR de-dup, closed-PR cache, existing semaphore and deadline |
| T-06-35 | Tampering (data integrity) | commit union | mitigate | Only own-branch PRs (TicketBranchRule) contribute, env-merge PRs never do; failed ADO steps keep Jira-only data flagged incomplete rather than partial-but-unflagged lists |
| T-06-36 | Denial of service | key rotation | mitigate | Undecryptable token degrades to ADO_CREDENTIAL_UNREADABLE; refresh still succeeds |
</threat_model>
