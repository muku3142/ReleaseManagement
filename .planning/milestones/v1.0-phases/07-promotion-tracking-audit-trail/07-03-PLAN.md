<objective>
Expose the promotion ledger over REST: read the history of a release and record a new entry, backed by a JPA adapter that locks
the release row, evaluates `PromotionHistory`, and inserts in one transaction.

Phase user story: **As a** release manager, **I want to** record each promotion of a frozen release through the environment ladder
and review its complete append-only history, **so that** I always know where every release sits and how it got there.

Purpose: after this plan the capability works end to end below the UI (curl-able); 07-04 puts the release-page UI on it, 07-05 and
07-06 add ladder editing and corrections on the same contracts.
Output: entities, JPA repositories, port, adapter, Clock bean, service, controller + DTOs, handler mappings, tests.
</objective>
