`releases(all)`:
1. `ledger = repository.loadLedger()`; group `ledger.promotions()` by `releaseId`; `production = stages.filter(Stage::production).findFirst()`.
2. Per release: `history = new PromotionHistory(r.id(), r.status() == ReleaseStatus.FROZEN, r.frozenAt(), ledger.stages(), entriesOrEmpty)`
   (read-only use; `frozen`/`frozenAt` only matter for `record`/`correct`); `current = history.currentStage()`;
   `shipped = history.firstProductionSuccess()` (D-08-01, D-08-16); `lastFailed = history.latestEffective().filter(p -> p.outcome() == FAILED).map(Promotion::stageId)` (D-08-02).
3. Visible (D-08-11, D-08-15): `inProduction = current.isPresent() && production.isPresent() && current.get().position() >= production.get().position()`;
   `visible = all || shipped.isEmpty() || !inProduction || !shipped.get().isBefore(now.minus(SHIPPED_WINDOW))` with `now = clock.instant()`.
4. One `repository.findChurnItems(visibleIds)` call, grouped by release id; `ReleaseChurn.of(itemsOrEmpty)` per visible release.
5. Durations in seconds (D-08-03): `createdToFrozen = frozenAt == null ? null : Duration.between(createdAt, frozenAt).toSeconds()`;
   `frozenToProduction = frozenAt != null && shipped present ? Duration.between(frozenAt, shipped).toSeconds() : null` (non-negative:
   D-08-14/D-07-06 only frozen releases are promoted and `deployed_at >= frozen_at` is enforced on record).
6. Summary over visible releases only: medians via `Stats.median` of the non-null seconds (boxed Double or null) with their counts
   (medians, not averages, D-08-03); `releasesPerStage` = `LinkedHashMap` in ladder order of stage id -> count of visible releases whose
   current stage is that stage (only stages with count > 0); `notPromoted` = visible releases with no current stage.
`deployments`: `rows = repository.findDeployments(stageId, from, to, limit + 1, offset)`; `hasMore = rows.size() > limit`;
entries = first `limit` rows. Comment: limit+1 avoids a count query; OFFSET pages can shift if promotions are recorded between loads,
acceptable for an audit list (Pitfall 4).
`ticketChurn`: `ReleaseChurn.of(repository.findChurnItems(List.of(releaseId))).perTicket()`.

Tests per `<behavior>` in `DashboardServiceTest` (Mockito mock of the port, `Clock.fixed(...)`, small builders for releases/promotions).
