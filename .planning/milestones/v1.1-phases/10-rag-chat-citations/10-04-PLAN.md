<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Document/history/transform text -> model prompt | Untrusted text enters the model's context |
| Model output -> citations | Model text must never become a citation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-14 | Tampering | Prompt injection via passages, titles, history, question, transform text | mitigate | Per-request random nonce fences; repeated-pass neutraliser for `<<<`, `>>>`, nonce and chat-template tokens; rules only in the system message |
| T-10-15 | Tampering | Residual injection that survives fencing on a 4B model | accept | Locked decision (SAFE-02): answers are plain text, nothing is executed; measured by golden cases G08/G09/T03 in plan 10-08/10-09; documented in docs/docker.md by plan 10-07 |
| T-10-16 | Spoofing | Fabricated citations from model text | mitigate | CitationBuilder takes only integer ids from the answer, validates them against the sent list, and copies metadata from SourceDocument; invented ids dropped and counted |
| T-10-17 | Denial of service | Silent num_ctx truncation dropping rules or question | mitigate | Pre-send budget with TEMPLATE_SLACK; history then sources dropped; question-too-large rejected rather than truncated |
| T-10-18 | Repudiation | Partial NO_ANSWER leaking as an answer | mitigate | RefusalGuard buffers until the prefix diverges and treats a truncated marker as a refusal |
</threat_model>
