<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Calling app -> ChatService.prepare | Tool definitions, turns and results are untrusted |
| Model output -> ChatService.run | Tool calls are untrusted and checked before they leave the service |
| ChatService -> logs | Metadata only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | Forged turn reaching the model | mitigate | verifyChain in prepare before assertReady and the gate; tested with zero readyCalls |
| T-11-04 | Denial of service | Runaway loop, held gate, oversized exchange | mitigate | Round cap with tools omitted at the cap, one correction retry, per-POST deadline, 413 budget check, releaseOnce before tool_call |
| T-11-06 | Information disclosure | Content in the log line | mitigate | Only counts, ids, validated names; canary test on arguments, results and signature |
| T-11-07 | Elevation of privilege | Service executing tools or calling an app | mitigate | No tool executor exists; the run only emits the signed calls to the caller (RAG-08) |
| T-11-17 | Denial of service | Spurious 429 on an immediate resume | mitigate | releaseOnce frees the slot before tool_call is sent; finally cannot double-release |
</threat_model>
