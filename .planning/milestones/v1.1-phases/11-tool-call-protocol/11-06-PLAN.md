## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | Forged turn over HTTP | mitigate | 400 TOOL_TURN_INVALID with zero Ollama requests, asserted via the WireMock journal |
| T-11-04 | Denial of service | Oversized bodies, lists or results | mitigate | Bean Validation backstops on list sizes and id lengths, existing request-size filter, 413 from the service for results |
| T-11-06 | Information disclosure | DTO toString in DEBUG request logging | mitigate | Content-free toString on every nested DTO; canary assertion |
| T-11-09 | Tampering | Hostile source url | mitigate | `https?://\S{1,2040}` pattern (same as documents); Phase 13 must still escape when rendering |
| T-11-18 | Information disclosure | Problem details echoing input | mitigate | Exception messages are fixed service texts; no argument, result or signature in problem detail |
