<interfaces>
Browser event protocol v1 (the contract 13-08 implements on the server; do not deviate):
```
POST /api/assistant/chat   Content-Type: application/json   Accept: text/event-stream, application/problem+json
body: {"question": string (1..1500, not blank), "history": [{"role":"user"|"assistant","content": string (1..4000)}], "releaseId": string uuid | null}
Pre-stream failures are normal problem+json responses: 400 (validation), 401 (session), 404 RELEASE_NOT_FOUND, 503.
Stream events (named SSE events, JSON data), terminated by exactly one `done` or `error`:
  event: status   data: {"tool":"deployments"}           a tool is about to run
  event: discard  data: {}                               the round became a tool call; drop its text
  event: token    data: {"text":"..."}
  event: done     data: {"refused":bool,"sources":[SourceView],"tools":[ToolView],"historyTrimmed":bool,"meta":{"model":string|null,"promptHash":string|null}}
  event: error    data: {"outcome":"OFFLINE"|"BUSY"|"MODEL_MISSING"|"DEADLINE"|"FAILED","retryAfterSeconds":number|null}
  : hb                                                    comment heartbeat, ignore
SourceView: {"n":number,"kind":"TICKET"|"DOCUMENT"|"MANUAL_ITEM"|"CODE_LINKS"|"TOOL","title":string|null,"releaseId":string|null,"releaseVersion":string|null,"ticketKey":string|null,"documentType":"RELEASE_NOTES"|"RUNBOOK"|"APPROVAL"|null,"revision":number|null}
ToolView: {"round":number,"name":string,"arguments":Record<string,unknown>,"error":boolean}
GET /api/assistant/status    -> {"enabled":false} | {"enabled":true,"starters":{"unscoped":string[],"release":string[]}}
GET /api/assistant/freshness -> {"lastIndexedAt": string | null}   (404 when off, 503 on rag failure)
```
From frontend/src/api/client.ts: `rawFetch` (private: JSON content type unless FormData, XSRF-TOKEN echo on non-GET,
`credentials: 'same-origin'`, ApiError on !ok), `apiFetch` (session-reason 401 -> `attemptRefresh()` once -> retry),
`ApiError(problem: ProblemDetail)`, `SESSION_REASONS`.
From frontend/src/api/queryClient.ts: `queryClient` (retry false). From api/auth.ts: `useSession()`.
</interfaces>

    export type Turn = { id: string; question: string; status: TurnStatus; phase: 'thinking' | 'tool' | 'answer';

      historyTrimmed: boolean; outcome: ErrorOutcome | null; retryAfterSeconds: number | null };
