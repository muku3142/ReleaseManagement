**`ReleaseJpaRepository.java`**:
```java
public interface ReleaseJpaRepository extends JpaRepository<ReleaseEntity, UUID> {

    // REL-05. Parameterised throughout - `:query` is a bound parameter concatenated by Postgres,
    // never by Java string building, so a value containing % _ ' or -- is matched literally as
    // data and cannot alter the statement. itemCount is the two item tables summed, which is what
    // the release library's Items column shows.
    @Query(value = """
            SELECT r.id                AS id,
                   r.name              AS name,
                   r.version           AS version,
                   r.status            AS status,
                   r.jira_project_key  AS jiraProjectKey,
                   r.created_at        AS createdAt,
                   r.created_by        AS createdBy,
                   r.frozen_at         AS frozenAt,
                   r.frozen_by         AS frozenBy,
                   r.last_refreshed_at AS lastRefreshedAt,
                   (SELECT count(*) FROM release_ticket_item t WHERE t.release_id = r.id)
                 + (SELECT count(*) FROM release_manual_item m WHERE m.release_id = r.id)
                                       AS itemCount
              FROM release r
             WHERE :query = ''
                OR r.name ILIKE '%' || :query || '%'
                OR r.version ILIKE '%' || :query || '%'
             ORDER BY r.created_at DESC
            """, nativeQuery = true)
    List<ReleaseSummaryRow> search(@Param("query") String query);

    // Only OPEN releases are valid targets for the Add-to-release picker (D-03-02).
    List<ReleaseEntity> findByStatusOrderByCreatedAtDesc(ReleaseStatus status);
}
```
Note: `findByStatusOrderByCreatedAtDesc` exists so plan 03-03's list endpoint can be filtered by
status without a second query shape. Import `ReleaseStatus` from `domain.release`.

**`create(Release release, List<ReleaseItem> items)`** — annotate `@Transactional`. This is the
single place D-03-02's "create-and-add is one transactional operation" is honoured; the analog is
`JiraCredentialRepositoryAdapter.upsert`.
```java
@Override
@Transactional
public Release create(Release release, List<ReleaseItem> items) {
    try {
        jpa.saveAndFlush(toEntity(release));
    } catch (DataIntegrityViolationException e) {
        // UNIQUE (name, version) - D-03-08. saveAndFlush forces the constraint to fire here
        // rather than at commit, where it would escape this catch.
        throw new ReleaseDuplicateException();
    }
    insertItems(release.id(), items);
    return load(release.id());
}
```
`DataIntegrityViolationException` is `org.springframework.dao.DataIntegrityViolationException`.

**`findById(UUID id)`** — `jpa.findById(id).map(e -> toDomain(e, ticketItems(id), manualItems(id)))`.

**`search(String query)`** — `jpa.search(query).stream().map(this::toSummary).toList()`. Map
`row.getStatus()` with `ReleaseStatus.valueOf(...)` and `row.getItemCount()` with `Math.toIntExact`.

**`findTicketKeys(UUID releaseId)`** —
`itemJpa.findByReleaseIdOrderByTicketKeyAsc(releaseId).stream().map(ReleaseTicketItemEntity::getTicketKey).toList()`.

**`addItems(UUID releaseId, List<ReleaseItem> items)`** — `@Transactional`; call the shared
`insertItems` helper, then `load(releaseId)`.

**`removeItem(UUID releaseId, String ticketKey)`** — `@Transactional`;
`itemJpa.deleteByReleaseIdAndTicketKey(releaseId, ticketKey)`, then `load(releaseId)`.

**`replaceItemSnapshots(UUID releaseId, List<ReleaseItem> items, Instant refreshedAt)`** —
`@Transactional`. For each supplied item, look it up with
`itemJpa.findByReleaseIdAndTicketKey(releaseId, item.ticketKey())`; if present, overwrite every
snapshot field (summary, issueType, status, resolution, assignee, reporter, fixVersions,
description, comments, commentTotal) and save — do NOT touch `addedAt`, which records when the
ticket joined the release, not when it was last read. Items whose key is absent from the supplied
list are left untouched. Then set the release's `lastRefreshedAt = refreshedAt` and save it.
Return `load(releaseId)`.

**`freeze(UUID releaseId, String actor, Instant at)`** — `@Transactional`; load the entity, set
`status = ReleaseStatus.FROZEN`, `frozenAt = at`, `frozenBy = actor`, save, return `load`.
There is no inverse method and none is ever to be added (D-03-10).

**`delete(UUID releaseId)`** — `@Transactional`; `jpa.deleteById(releaseId)`. The
`ON DELETE CASCADE` foreign keys in V3 remove the items; do not delete children by hand.

**`addManualItem(UUID releaseId, ManualItem item)`** — `@Transactional`; build a
`ReleaseManualItemEntity` from the domain record (its id is already assigned by
`ManualItem.create`), set `releaseId`, save, return `load(releaseId)`.

**`updateManualItem(UUID releaseId, ManualItem item)`** — `@Transactional`;
`manualJpa.findByReleaseIdAndId(releaseId, item.id()).orElseThrow(ReleaseNotFoundException::new)`,
overwrite title/description/category (never `addedAt`, never `releaseId`), save, return `load`.

**`removeManualItem(UUID releaseId, UUID manualItemId)`** — `@Transactional`;
`manualJpa.findByReleaseIdAndId(releaseId, manualItemId).ifPresent(manualJpa::delete)`, return `load`.

**Private helpers:**
- `private Release load(UUID id)` — `findById(id).orElseThrow(ReleaseNotFoundException::new)`
- `private void insertItems(UUID releaseId, List<ReleaseItem> items)` — map each `ReleaseItem` to a
  `ReleaseTicketItemEntity` with `UUID.randomUUID()` as the id, `releaseId` set, and every
  `TicketDetail` field copied across; `itemJpa.saveAll(...)`
- `private static Release toDomain(ReleaseEntity e, List<ReleaseItem> items, List<ManualItem> manualItems)`
- `private static ReleaseItem toDomain(ReleaseTicketItemEntity e)` — rebuilds the `TicketDetail`
  from the columns in the order `(key, summary, issueType, status, resolution, assignee, reporter,
  fixVersions, description, comments, commentTotal)`
- `private static ManualItem toDomain(ReleaseManualItemEntity e)`
- `private static ReleaseSummary toSummary(ReleaseSummaryRow row)`

The adapter must never leak a JPA entity out through a port method, and no other class in the
codebase may import `ReleaseJpaRepository`, `ReleaseTicketItemJpaRepository` or
`ReleaseManualItemJpaRepository`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service layer -> SQL | REL-05's search string is end-user text arriving from the release library's search box and reaching a SQL statement |
| Domain -> database transaction | D-03-02's "one transaction" promise is kept or broken here and nowhere else |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | `ReleaseJpaRepository.search` | mitigate | The search term is a bound `@Param("query")`; the `%` wildcards are concatenated by PostgreSQL (`'%' \|\| :query \|\| '%'`), never by Java. `searchTreatsSqlWildcardsAndQuotesAsLiteralText` in the IT asserts `'; DROP TABLE release; --` returns no rows and leaves the table intact |
