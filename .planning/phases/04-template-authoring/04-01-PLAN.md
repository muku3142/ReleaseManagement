<objective>
Build the fixed view-model, the exhaustive placeholder catalog and the template scanner that
enforces the allowed Mustache subset — the three pure-domain artefacts that make everything else
in this phase safe. Zero external libraries, zero Spring, zero persistence.

Purpose: `.planning/ROADMAP.md:107` makes engine and view-model design the first work inside this
phase because it is the project's highest-risk decision. `PROJECT.md` §Key Decisions locks that
templates see a dedicated flattened view-model, never a domain record or JPA entity — this plan is
that view-model. TMPL-02's "no expression language, no method invocation, no arbitrary property
traversal" becomes an asserted property of *this codebase* rather than a hope about jmustache's
defaults.

Output: `domain/template/view/*` records, `PlaceholderCatalog`, `TemplateScanner`, the two render
exceptions, and the drift test that keeps the catalog honest.
</objective>

public static Optional<PlaceholderEntry> find(PlaceholderScope scope, String token) {
    return ENTRIES.stream()
            .filter(e -> e.scope() == scope && e.token().equals(token))
            .findFirst();
}
