<objective>
Build the document viewer route the phase designed but never shipped:
`/releases/$releaseId/documents/$documentType`.

Purpose: `05-UI-SPEC.md` designs this as "screen 2" and every View affordance the phase built points
at it — `ReadinessPill`'s green "Up to date" and amber "Stale" pills, `DocumentsSection`'s View action

it is the only thing blocking ROADMAP Success Criterion 4's "preview" half.

them from plain `<a href>` to typed `<Link>` is the finishing move both summaries flagged.
