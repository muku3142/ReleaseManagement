```java
public record PromotionHistory(UUID releaseId, boolean frozen, Instant frozenAt, List<Stage> stages, List<Promotion> entries) {

    // D-07-10 / RESEARCH A2: a browser clock slightly ahead of the server must not make "now" look like the future.
    public static final Duration FUTURE_TOLERANCE = Duration.ofMinutes(2);

    // D-07-13: "later" = later deployed_at, tie-broken by recorded_at.
    public static final Comparator<Promotion> LEDGER_ORDER =
            Comparator.comparing(Promotion::deployedAt).thenComparing(Promotion::recordedAt);

    public PromotionHistory {   // stages sorted ascending by position; both lists copied (List.copyOf)
    }
    public Optional<UUID> supersededBy(UUID promotionId)     // id of the entry whose supersedesId == promotionId
    public boolean isEffective(Promotion promotion)          // supersededBy(promotion.id()).isEmpty()  (D-07-11)
    public Optional<Stage> currentStage()
    public Optional<Stage> nextStage()
    public Promotion record(PromotionDraft draft, String actor, Instant now)
}
```

Semantics (implement exactly):
- `counted` entries = effective AND outcome != VOIDED (D-07-11, D-07-15). Every rule below uses only counted entries.
- `hasStandingSuccess(stageId)`: among counted entries on that stage with outcome SUCCESS or ROLLED_BACK, the max by `LEDGER_ORDER`
  exists and is SUCCESS. FAILED is ignored (D-07-08).
- `currentStage()`: stages from highest position to lowest (retired included), first with a standing SUCCESS.
- `nextStage()`: lowest-position non-retired stage whose position is greater than the current stage's position (or than
  `Integer.MIN_VALUE` when there is no current stage) (D-07-07).
- `record(draft, actor, now)`, checks in this order, each throwing `new PromotionRejectedException(PromotionRejection.X)`:
  1. `!frozen` -> RELEASE_NOT_FROZEN (D-07-06)
  2. outcome VOIDED -> PROMOTION_OUTCOME_NOT_RECORDABLE (D-07-15)
  3. `nowMicros = now.truncatedTo(MICROS)`; `deployedAt = (draft.deployedAt() == null ? nowMicros : draft.deployedAt().truncatedTo(MICROS))`;
     if `deployedAt.isAfter(nowMicros.plus(FUTURE_TOLERANCE)) || deployedAt.isBefore(frozenAt)` -> PROMOTION_DEPLOYED_AT_INVALID (D-07-10).
     (Postgres stores microseconds; truncating keeps in-memory comparisons identical to what is read back.)
  4. target = stage by `draft.stageId()`, else `throw new StageNotFoundException()`; `target.retired()` -> PROMOTION_TARGET_RETIRED
  5. outcome ROLLED_BACK (D-07-13): if no counted SUCCESS on the target that is standing and whose deployedAt is not after `deployedAt`
     -> PROMOTION_ROLLBACK_WITHOUT_SUCCESS ("standing" = after the last ROLLED_BACK on that stage by `LEDGER_ORDER`); else if target is not
     `currentStage()` -> PROMOTION_STAGE_SKIPPED.
  6. outcome SUCCESS or FAILED: target must equal `nextStage()` or `currentStage()`, else PROMOTION_STAGE_SKIPPED (D-07-07).
  7. return `new Promotion(UUID.randomUUID(), releaseId, target.id(), outcome, deployedAt, nowMicros, actor, trimToNull(note), null, null)`.
- No Spring, no `Instant.now()` and no I/O inside this class: time arrives as a parameter.
Keep helpers private; one short WHY comment per non-obvious rule citing its decision id.
