## Trust Boundaries

| Boundary | Description |
|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-32 | Spoofing | ApiKeyFilter | mitigate | 256-bit keys looked up by SHA-256; admin key compared with `MessageDigest.isEqual`; startup refuses admin keys < 32 chars |
| T-09-33 | Elevation of privilege | Client key on admin routes | mitigate | `/v1/admin/**` accepts only the admin key; tested 401 with a valid client key |
| T-09-34 | Information disclosure | Foreign collection | mitigate | `require(clientId, name)` -> 404 for absent and foreign alike; tested (D-09-03) |
| T-09-35 | Information disclosure | Key leakage | mitigate | Key in create/rotate responses only; never logged; ClientResponse has no key field |
| T-09-36 | Repudiation | Unused/abused keys | mitigate | `last_used_at` recorded (D-09-04) and visible via GET /v1/admin/clients |
| T-09-37 | Tampering | Path variable injection | mitigate | `@Pattern` on names; all SQL parameterised (plan 05) |
| T-09-38 | Spoofing | Admin key over plain HTTP | accept | Internal service on a host network, same exposure model as the v1 app; TLS termination is a deployment concern outside this phase |
