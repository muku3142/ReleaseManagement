         * `passages = chunker.chunk(title, text)`; empty -> `queue.fail(id, hash, "Document has no indexable text")`; continue.

             The document stays PENDING and is never FAILED for an outage (D-09-10, D-09-12). One failed call per tick, not per document.
           - `EmbeddingRejectedException`: `queue.fail(id, hash, "Embedding model rejected the content")`; `log.info("Document {} failed: content rejected", id)`; continue.

         * After any successful embed call: `backoff = null; notBefore = Instant.EPOCH`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client app -> document endpoints | Untrusted bodies up to 1 MB of text |
| Worker -> Ollama | Untrusted availability and responses |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-39 | Denial of service | Oversized bodies | mitigate | Content-Length filter (2 MB) before auth and parsing; 1 MB UTF-8 text check after parsing (D-09-08) |
| T-09-40 | Denial of service | Unbounded chunked bodies | accept | Internal, key-authenticated service; post-parse check bounds stored text (RESEARCH A4) |
| T-09-41 | Tampering | NUL bytes causing 500s | mitigate | `rejectNul` on title, text, url -> 400 |
| T-09-42 | Information disclosure | Cross-client document access | mitigate | Every route resolves the collection through `CollectionService.require(clientId, ...)`; tested with client B |
| T-09-43 | Denial of service | Ollama outage exhausting DB pool | mitigate | Embedding outside transactions; claim released; worker-level backoff capped at 5 min |
| T-09-44 | Information disclosure | Logs | mitigate | Worker and services log ids/counts/durations only (locked rule); acceptance grep on log arguments |
| T-09-45 | Tampering | Stored XSS via citation URL in a later UI | mitigate | URL must match `https?://\S{1,2040}` |
| T-09-46 | Tampering | Prompt-injection text in documents | accept | Stored as data only in this phase; fencing is Phase 10 |
</threat_model>
