## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client app -> search/status | Untrusted query text and filters |
| rag-service -> Ollama (synchronous on search) | External dependency on the request path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-47 | Information disclosure | Cross-client search | mitigate | `require(clientId, ...)` before embedding; ChunkSearch scoped by collection id; tested 404 + zero Ollama calls |
| T-09-48 | Denial of service | Large k / long query | mitigate | k capped at 50; query max 2000 chars; filters capped by MetadataRules |
| T-09-49 | Tampering | Filter injection | mitigate | Filters parsed by MetadataRules and bound as jsonb (plan 06) |
| T-09-50 | Information disclosure | Queue depth across tenants | mitigate | `queueDepth(clientId)` counts only the caller's documents (tested with client B excluded) |
| T-09-51 | Information disclosure | Query text in logs | mitigate | No query logging in SearchService (acceptance check) |
| T-09-52 | Denial of service | Ollama outage on search path | mitigate | Read timeout PT60S + 503 EMBEDDING_UNAVAILABLE; readiness unaffected |
</threat_model>
