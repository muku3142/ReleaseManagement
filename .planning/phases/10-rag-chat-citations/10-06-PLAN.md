    4. `ChatController` (`@RestController`, no class-level `@Validated`), constructor `(ChatService chat, TransformService transform, ChatProperties props)`:
       ```java
       @PostMapping("/v1/chat")
       public ResponseEntity<SseEmitter> chat(
               @Parameter(hidden = true) @RequestAttribute(ApiKeyFilter.CLIENT_ID_ATTRIBUTE) UUID clientId,
               @Valid @RequestBody ChatRequest request) {
           ChatService.Plan plan = chat.prepare(clientId, request.toCommand());   // all 400/404/429/503 thrown here, before commit
           return stream(plan.cancellation(), sink -> chat.run(plan, sink));
       }
       @PostMapping("/v1/transform")  ... same with transform.prepare / transform.run

       private ResponseEntity<SseEmitter> stream(Cancellation cancellation, Consumer<EventSink> work) {
           SseEmitter emitter = new SseEmitter(props.deadline().plusSeconds(15).toMillis());   // backstop; the watchdog fires first
           emitter.onCompletion(() -> cancellation.cancel(CancelReason.CLIENT_GONE));  // no-op after a recorded outcome
           emitter.onError(e -> cancellation.cancel(CancelReason.CLIENT_GONE));
           emitter.onTimeout(() -> cancellation.cancel(CancelReason.DEADLINE));
           SseSink sink = new SseSink(emitter, cancellation);
           Thread.ofVirtual().name("generation").start(() -> work.accept(sink));  // run() releases the gate in finally
           return ResponseEntity.ok().contentType(MediaType.TEXT_EVENT_STREAM)
                   .header(HttpHeaders.CACHE_CONTROL, "no-cache").header("X-Accel-Buffering", "no").body(emitter);
       }
       ```
       Sends before the handler attaches are buffered by the emitter (RESEARCH), so starting the thread before returning is safe.
       Callbacks only call `cancel` (non-blocking; they run under the async request's state lock and must never `send`).
       Document both operations with `@Operation(summary = ...)` and
       `@ApiResponse(responseCode = "200", description = EVENTS, content = @Content(mediaType = "text/event-stream", schema = @Schema(type = "string")))`
       where `EVENTS` is one constant string: "Server-sent events. status {requestId, phase: SEARCHING|GENERATING}; token {text};
       citations {basis: MARKED|RETRIEVED, items: [{n, documentId, title, url, collection, metadata}]} (chat only);
       done {refusal, refusalLayer: GATE|MODEL|null, finishReason, truncated, promptTokens, completionTokens};
       error {reason: DEADLINE|GENERATION_FAILED|OLLAMA_UNAVAILABLE|MODEL_NOT_AVAILABLE|EMBEDDING_UNAVAILABLE|INTERNAL}.
       Comment lines are heartbeats. Errors before the stream opens are problem+json: 400, 404, 413 (transform), 429 with
       Retry-After, 503 (reason OLLAMA_UNAVAILABLE or MODEL_NOT_AVAILABLE)."
