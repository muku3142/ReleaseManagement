<objective>
Teach the Ollama adapter the native tool wire contract: send tool definitions, replay tool rounds, accumulate streamed
`tool_calls`, choose `think` by capability for tool requests, expose `assertToolsReady()` on the port, and report
`eval_duration`. Extend the fake Ollama server so later plans can script multi-request tool exchanges.

Purpose: the only outbound call stays Ollama (SAFE-03, RAG-08), and Ollama shapes never leak through `ChatPort`
(AI-SPEC section 3, "Observed Ollama 0.34.0 wire contract").
Phase 10 dependence: may execute before Phase 10 closes. The no-tools request body must stay byte-identical; only the
`think` line could collide with Phase 10's open debug, see `phase10_gate`.
Output: adapter changes, port method, two test-helper extensions, adapter tests.
</objective>
