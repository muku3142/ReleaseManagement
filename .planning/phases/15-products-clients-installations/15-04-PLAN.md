`ReleaseProductRepositoryAdapter implements ReleaseProductRepository` (`@Component`, deps `ReleaseJpaRepository`, `ProductJpaRepository`):
- `productsOf(releaseId)` = `productsOfReleases(List.of(releaseId)).getOrDefault(releaseId, List.of())`.
- `productsOfReleases(ids)`: empty input -> `Map.of()`; else group the native rows by releaseId preserving order into `ReleaseProduct(id, name, archivedAt != null, hasInstalls)`.
- `replace(releaseId, requested)`, `@Transactional`, exactly the RESEARCH Pattern 3 sketch:
  ```java
  ReleaseEntity release = releaseJpa.findByIdForUpdate(releaseId).orElseThrow(ReleaseNotFoundException::new);
  // D-15-01: deliberately no lockOpen/requireOpen - products stay editable after FROZEN so v1.1 releases can be tagged.
  Set<UUID> current = Set.copyOf(productJpa.findProductIdsOfRelease(releaseId));
  Set<UUID> added = difference(requested, current); Set<UUID> removed = difference(current, requested);
  ```
  Then, before any other check: `if (requested.isEmpty()) throw new PortfolioEditRejectedException(PortfolioEditRejection.RELEASE_LAST_PRODUCT);` (one-line comment: D-15-18, a release always keeps at least one product). This is the single server-side home of the never-empty rule; `ReleaseService.setProducts` delegates to it (plan 08).
  For each added id: `productJpa.findById` -> `ProductNotFoundException`; archived -> `PortfolioEditRejectedException(PRODUCT_ARCHIVED)` (D-15-07). If `removed` intersects `findProductIdsWithInstalls(releaseId)` -> `PortfolioEditRejectedException(PRODUCT_HAS_INSTALLS_ON_RELEASE)` (D-15-15). Validate everything before writing. Then delete only `removed`, insert only `added` (never delete-all/insert-all, Pitfall 5). If either set is non-empty: `release.setItemsChangedAt(Instant.now())` (D-15-02; one-line comment: unchanged set must not stamp, WR-01) - the entity is managed, so no explicit save is needed beyond the transaction; call `releaseJpa.save(release)` only if the existing adapter does so after stamping.

`PortfolioPersistenceIT` (`@SpringBootTest @Testcontainers`, PgVectorImage container, `@AfterEach` `TRUNCATE release CASCADE` + `TRUNCATE product, client CASCADE`). Tests (via the ports, autowired):
