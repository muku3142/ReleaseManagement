# Phase 15.1 Plan 06: Release detail unfreeze UI Summary

A frozen release shows a gray "Unfreeze release" button above the banner; it opens a confirm dialog, unfreezes, focuses "Add tickets" and announces the result through a screen-reader status region. When the server reports `unfreezeBlockedReason` the button is aria-disabled with a linked reason line, and a server rejection lands in the existing alert paragraph. Freeze dialog and banner copy were revised, and an amber out-of-date-documents note appears after an unfreeze when readiness reports a STALE document.
