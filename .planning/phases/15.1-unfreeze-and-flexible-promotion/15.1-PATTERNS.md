### `ReleaseRepositoryAdapter.unfreeze` (adapter, CRUD under row lock)

**Analog:** same file. Constructor L57-67 takes jpa repos plus `publisher`; add `PromotionJpaRepository promotionJpa` and `ClientDeploymentJpaRepository clientDeploymentJpa` (same two-JPA-repo pattern as `PromotionRepositoryAdapter`).

**Freeze to mirror** (L251-261):
```java
@Override
@Transactional
public Release freeze(UUID releaseId, String actor, Instant at) {
    ReleaseEntity entity = lockOpen(releaseId);
    entity.setStatus(ReleaseStatus.FROZEN);
    entity.setFrozenAt(at);
    entity.setFrozenBy(actor);
    jpa.save(entity);
    publisher.publishEvent(new ReleaseIndexInvalidated(releaseId));
    return load(releaseId);
}
```
**Lock to mirror** (L323-329): `jpa.findByIdForUpdate(releaseId).orElseThrow(ReleaseNotFoundException::new)`. Do NOT call `lockOpen` (it rejects FROZEN); call `findByIdForUpdate` directly, then check `status != FROZEN`, then `promotionJpa.existsByReleaseId`, then `clientDeploymentJpa.existsByReleaseId`, then set OPEN and null `frozenAt`/`frozenBy`, save, publish `ReleaseIndexInvalidated`, `return load(releaseId)`. Full body is in 15.1-RESEARCH.md Pattern 1. Do not touch `items_changed_at` (Open Question 3). The other ledgers take the same lock before reading `frozen`: `PromotionRepositoryAdapter.appendUnderLock` L40-48:

**Source:** `GlobalExceptionHandler.problem(...)` L481-487; SPA keys copy on `reason` via `messageForReason` in `auth.ts`. **Apply to:** all new rejections and the renamed code.

**Source:** `publisher.publishEvent(new ReleaseIndexInvalidated(releaseId))` after every mutating adapter method (L84, 131, 144, 159, 184, 259, ...). **Apply to:** `unfreeze`.

### ConfirmDialog + onSettled close

## Pitfalls specific to this mapping

- CONTEXT claims `PROMOTION_STAGE_SKIPPED` is raised in correction replay; it is not. The second occurrence (L132) is in `checkRollback`. Do not add or remove a sequence rule in `correct()`.
- `lockOpen` cannot be reused for unfreeze (it throws on FROZEN).
- `DocumentReadinessService.state` signature change ripples to `DocumentsTool` consumers only through `ReadinessEntry`; callers of `state(` outside `all()` need a grep.
- UI-SPEC reason-code names are placeholders; use the server enum names.
- Phase 16 plans (untracked) contain the "frozen releases never go stale (D-05-09)" tooltip (16-06); update there, not here.
