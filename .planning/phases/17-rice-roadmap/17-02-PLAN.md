  <behavior>
    - RiceInputs.validated(reach=-1) -> ROADMAP_REACH_INVALID; reach=2.5 -> ROADMAP_REACH_INVALID; reach=1_000_001 -> ROADMAP_REACH_INVALID; reach=0 ok; reach=10.00 ok (stored 10)
    - impact=0.75 -> ROADMAP_IMPACT_INVALID; impact=0.50 ok and equals canonical 0.5 by compareTo
    - confidence=70 -> ROADMAP_CONFIDENCE_INVALID; confidence=80.5 -> ROADMAP_CONFIDENCE_INVALID; 50/80/100 ok
    - effort=0 or -1 -> ROADMAP_EFFORT_INVALID; effort=0.125 -> ROADMAP_EFFORT_INVALID; effort=1000000 -> ROADMAP_EFFORT_INVALID; effort=0.5 ok
    - all four null -> valid, complete()=false, missing()=[REACH, IMPACT, CONFIDENCE, EFFORT]
    - score(10, 2, 80, 4) = 4 (compareTo); score(0, 3, 100, 1) = 0 (scored); score(1, 1, 100, 3) = 0.33333... (no ArithmeticException); any null -> empty
    - changedFields(previous): only fields whose value differs by compareTo, in R,I,C,E order; null->value and value->null count as changes; 2.0 vs 2.00 is NOT a change
    - rank: [unscored old, scored 5, scored 10, unscored new] -> [10 (rank 1), 5 (rank 2), unscored old (rank null), unscored new (rank null)]
    - rank tie: equal scores -> higher impact first; equal impact -> earlier createdAt first; equal createdAt -> smaller id (UUID.compareTo) first
    - rank is stable under shuffled input (same output for 20 random permutations)
  </behavior>
