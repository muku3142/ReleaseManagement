<interfaces>
HTTP CONTRACT (authoritative for 17-07, 17-10, 17-13). All JSON; errors are ProblemDetail with `reason`.

Roadmap item JSON (`RoadmapItem`):
```ts
{ id: string; source: 'JIRA' | 'MANUAL'; jiraKey: string | null; title: string;
  jiraStatus: string | null; jiraSyncedAt: string | null; jiraUnavailable: boolean;
  product: { id: string; name: string; archived: boolean } | null;
  status: 'IDEA' | 'PLANNED' | 'IN_PROGRESS' | 'DONE'; targetQuarter: string | null; owner: string | null; notes: string | null;
  reach: number | null; impact: number | null; confidence: number | null; effort: number | null;
  scoreDisplay: string | null;   // server-rounded to 1 decimal HALF_UP (D-17-17); null when unscored
  rank: number | null;           // 1..n among scored rows of THIS response; null when unscored
  missing: ('REACH' | 'IMPACT' | 'CONFIDENCE' | 'EFFORT')[];
  createdAt: string; archived: boolean }
```
| Method + path | Body | 2xx response |
|---|---|---|
| GET `/api/roadmap/items?productIds=a,b&done=true&archived=true` (all optional) | - | 200 `{ items: RoadmapItem[] }` in server rank order |
| POST `/api/roadmap/items` | `{ title: string, productId: string \| null }` | 201 `RoadmapItem` |
| POST `/api/roadmap/items/jira` | `{ keys: string[] }` (1..100) | 200 `{ added: {itemId, jiraKey}[], alreadyPresent: {jiraKey, itemId}[], notFound: string[] }` |
| POST `/api/roadmap/items/from-release` | `{ releaseId: string, ticketKeys: string[] }` (1..100) | 200 same add result |
| PUT `/api/roadmap/items/{id}/inputs` | `{ reach, impact, confidence, effort }` all `number \| null` (full replace) | 200 `RoadmapItem` (rank null) |
| PUT `/api/roadmap/items/{id}/details` | `{ title: string \| null, status, productId: string \| null, targetQuarter: string \| null, owner: string \| null, notes: string \| null }` | 200 `RoadmapItem` (rank null) |
| POST `/api/roadmap/items/{id}/archive` and `/restore` | - | 204 |
| GET `/api/roadmap/items/{id}/history` | - | 200 `{ entries: { field, oldValue: number \| null, newValue: number \| null, changedAt: string, changedBy: string }[] }` newest first |
| POST `/api/roadmap/refresh` | - | 200 `{ refreshed: number, unavailable: {itemId, jiraKey}[] }` |
| POST `/api/roadmap/items/{id}/refresh` | - | 200 same refresh result |
| GET `/api/roadmap/export.csv?productIds=..&done=..&archived=..` | - | 200 `text/csv; charset=utf-8`, attachment `roadmap-YYYY-MM-DD.csv` |
| PUT `/api/releases/{id}/packages-url` | `{ url: string \| null }` (null/blank clears) | 200 `Release` (now with `packagesUrl: string \| null`) |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL search params -> SPA state | `products`, `done`, `archived`, `item` are attacker-controllable links |
| SPA -> API | state-changing calls go through apiFetch (X-XSRF-TOKEN, SameSite=Strict cookie) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Tampering | parseRoadmapSearch | mitigate | UUID regex for ids, literal 'true' for flags, cap at MAX_PRODUCT_FILTER; malformed -> default |
| T-17-11 | Spoofing | CSRF on new mutations | mitigate | all mutations use apiFetch (existing CSRF header + SameSite=Strict, locked decision) |
| T-17-12 | Information disclosure | error messages | accept | REASON_MESSAGES are static strings; no server detail echoed |
</threat_model>
