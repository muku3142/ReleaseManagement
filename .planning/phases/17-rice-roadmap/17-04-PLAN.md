    - `setArchivedAt`, `applyJiraSnapshot`, `markJiraUnavailable`: RoadmapItemNotFoundException when the update count is 0 and the
      item does not exist (`markJiraUnavailable` legitimately returns 0 for an already-flagged item, so check existence, not the count).
