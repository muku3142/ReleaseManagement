<interfaces>
HTTP contract (shared with 17.1-13 and 17.1-15; exact):
```ts
export type DayCode = 'SUN' | 'MON' | 'TUE' | 'WED' | 'THU' | 'FRI' | 'SAT';
export type BriefingTaskSettings = { id: 'jira_digest' | 'sprint_check' | 'weekly_status'; name: string; enabled: boolean;
  days: DayCode[]; time: string /* HH:mm */; staleAfterWorkingDays: number; dueSoonDays: number; backlogItems: number };
export type BriefingSettings = {
  claudeFeed: { dataDir: string; configFile: string; readable: boolean };
  schedulerUser: { email: string | null; isYou: boolean };
  credentialProblem: boolean;   // no scheduler user, or the newest non-skipped app run is needs_credential
  graceMinutes: number; workDays: DayCode[]; keepRuns: number; tasks: BriefingTaskSettings[] };
export type BriefingSettingsUpdate = { graceMinutes: number; workDays: DayCode[]; keepRuns: number;
  tasks: Omit<BriefingTaskSettings, 'name'>[] };
export type BriefingRunNowResult = { task: string; name: string; products: number; attention: number; failed: number; needsCredential: number; skipped: number };
```
- `GET /api/settings/briefings` -> BriefingSettings (effective values: config.json defaults applied)
- `PUT /api/settings/briefings` body BriefingSettingsUpdate -> BriefingSettings; 400 `VALIDATION_FAILED` (fieldErrors keyed like `graceMinutes`, `tasks[0].time`) or 400 `BRIEFING_SETTINGS_INVALID`
- `PUT /api/settings/briefings/scheduler-user` (no body) -> BriefingSettings; 422 `BRIEFING_NO_JIRA_CREDENTIAL`
- `POST /api/settings/briefings/tasks/{id}/run` -> BriefingRunNowResult (always 200 on a recorded run, never 401 for the scheduler credential); 400 `BRIEFING_TASK_NOT_RUNNABLE`; 409 `BRIEFING_TASK_DISABLED`
Query key `['briefing-settings']`; save, designate and run-now invalidate `['briefings']`; save and designate `setQueryData` the response.
Existing: `apiFetch`, `ApiError`, `messageForReason` (`api/reasonMessages.ts`), `SectionLoading`, `SectionError`, `SMALL_BUTTON`, Spinner markup
(`h-4 w-4 animate-spin motion-reduce:animate-none rounded-full border-2 border-gray-300 border-t-blue-600`), `SettingsRoute` (`max-w-xl` container, `AzureDevOpsSection`), `api/jiraSite.ts` hook style.
