<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| background job -> Jira | runs with the self-designated user's token while that user is absent |
| Jira text -> model | untrusted summaries enter the model prompt |
| model -> stored briefing | model output is untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17.1-37 | Elevation of privilege | scheduler credential | mitigate | self-designation only (D-17.1-19), loaded fresh per run, read-only port, ArchUnit allowlist of credential readers |
| T-17.1-38 | Information disclosure | token in logs/bodies | mitigate | context never logged or stored; log class names only |
| T-17.1-39 | Denial of service | Jira hammering after 401/429 | mitigate | stop all Jira calls after the first 401 in a call; 429 recorded, no retry |
| T-17.1-40 | Tampering (prompt injection) | headline | mitigate | model output limited to headline/summary, validated (length, single line, keys must be in the facts), else rule text kept |
| T-17.1-41 | Denial of service | slow model | mitigate | caller-side deadline with cancel; run never waits beyond it |
| T-17.1-42 | Repudiation | which credential ran | accept | single designated user recorded in settings; runs are system actions |
</threat_model>
