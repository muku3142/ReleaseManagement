# Phase 17.1 Plan 14: Briefing Scheduler Summary

A one-minute fixedDelay tick, scheduled unconditionally so it also runs with the assistant off. Each tick takes the latest Africa/Cairo cron slot (DST-correct) for every enabled task, once grace has passed and within the 12 h catch-up window. It checks Claude's feed for a non-failed row in [slot - 5 min, slot + grace], then calls `BriefingRunner.runSlot` with the covered projects. The whole tick is gated on the D-17.1-24 fallback switch.
