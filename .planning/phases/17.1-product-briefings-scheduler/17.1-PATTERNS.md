## Pattern Assignments

### `B/domain/briefing/*` (model, transform) and `B/ports/BriefingReadPort.java`

**Analogs:** `B/ports/RagTransformPort.java`, `B/ports/JiraTicketPort.java`; domain has NO Spring/Jakarta/Jackson imports (`ArchitectureBoundaryTest.domainAndPortsHaveNoFrameworkImports`, line 41).

Port style: one short method, Javadoc only for the non-obvious (RagTransformPort.java 5-9):

```java
public interface RagTransformPort {
    // Service errors come back as TransformOutcome, never thrown; exceptions thrown by the listener propagate.
    TransformOutcome transform(String text, String instruction, RagChatPort.ChatListener listener);
}
```

Apply: `BriefingFeed BriefingReadPort.feed(BriefingTask task)` (RESEARCH says the reader returns a parsed `BriefingFeed` with `readError`, and the fallback check reuses it; the build prompt's `List<BriefingRun> runs(task)` cannot carry `readError`, so return the feed). Errors come back as `readError=true`, never thrown. `BriefingTask` enum carries `id`, display name, schedule text (build prompt table). `BriefingStatus` needs `ok, attention, quiet, failed, setup` for the file and `needs_credential, skipped` for app runs; keep `setup` parse-only and dropped.

### `B/adapters/briefing/FileBriefingReadAdapter.java` (adapter, file-I/O)

**Analog (partial):** `B/adapters/jira/JiraRestTicketAdapter.java`: `@Component`, tools.jackson `JsonNode`, defensive per-row extraction so one bad row does not fail the read.

Imports to copy (lines 19-20): `tools.jackson.databind.JsonNode`, `tools.jackson.databind.node.MissingNode`. Jackson 3 is `tools.jackson.databind`; annotations stay `com.fasterxml.jackson.annotation`. Parse with an injected `JsonMapper`/`ObjectMapper` (Boot bean), not `new`.

Defensive timestamp pattern (lines 175-182): catch `DateTimeParseException`, return null, row dropped:

```java

    try { return JiraTimestamps.parse(fields.path(UPDATED_FIELD).asText(null)); }
    catch (DateTimeParseException e) { return null; }
}
```

Log convention for failures (IndexSweep.java line 54, metadata only, never the message because it can hold the path):

```java
log.warn("rag index sweep failed exceptionType={}", e.getClass().getSimpleName());
```

Mandatory rules (CONTEXT D-17.1-15, RESEARCH Q10): file name only `task.id() + ".json"` from the enum; `resolve`, `normalize`, assert `startsWith(base)`; `Files.readAttributes(..., NOFOLLOW_LINKS)` rejects symlinks and non-regular files; read at most 1 MB + 1 bytes; cap newest 60; truncate by code points (140 headline, 120 h1-h3); strip control and bidi characters; drop `setup`, unknown status, bad `run_at`, negative `attention`. Missing dir or file: empty, `readError=false`. Anything else: empty, `readError=true`. No existing file-reading adapter to copy; `@TempDir` tests with decoy `other.json` and a symlink for B6.

### Error contract (ProblemDetail reason codes)
**Source:** `B/adapters/web/GlobalExceptionHandler.java` (`problem(...)` 496-501) and `F/api/auth.ts` `REASON_MESSAGES` + `messageForReason`.
**Apply to:** `PRODUCT_JIRA_KEY_TAKEN` (409), `PRODUCT_JIRA_KEY_INVALID` (400), `BRIEFING_NO_JIRA_CREDENTIAL`, settings validation. Every new reason needs a backend handler and a frontend message in the same plan. Frontend rendering:

```tsx
const problem = save.isError && save.error instanceof ApiError ? save.error.problem : undefined;
{problem && <p role="alert" data-reason={problem.reason} className="mt-2 text-sm text-red-600">{messageForReason(problem)}</p>}
```

### Injected Clock, UTC
**Source:** `B/config/ClockConfig.java` bean, used as in `ProductService` (`clock.instant()`). **Apply to:** schedule tick, runner, pruning, headline timing. Never `Instant.now()`. Convert to Africa/Cairo only at the slot/working-day edge (`atZone(ZoneId.of("Africa/Cairo"))`), never add 24 h to an instant.

### Logging
**Source:** `IndexSweep` line 51-54. Metadata only (counts, status, durationMs, exception class). Never Jira summaries, Claude headlines, file paths, tokens (SAFE-03).

### Read-only Jira, hexagonal boundaries
**Source:** `ArchitectureBoundaryTest` lines 41-75 (domain/ports free of Spring and Jackson; application never imports `adapters.*`). `FileBriefingReadAdapter` and `BriefingConfigFileAdapter` live in `adapters/briefing`, so `application` reaches them only through ports (`BriefingReadPort`, `BriefingCoverageSource`). `Jackson` types stay in the adapters.
