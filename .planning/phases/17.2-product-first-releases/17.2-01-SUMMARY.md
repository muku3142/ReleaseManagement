# Phase 17.2 Plan 01: One product per release (backend) Summary

Flyway V23 adds `UNIQUE (release_id)` to `release_product`. Release creation now takes a single `productId` and derives `jira_project_key` from the product's first mapped Jira key. It rejects an unmapped product with `PRODUCT_NO_JIRA_PROJECT` (422) before any Jira call. `PUT /api/releases/{id}/product` replaces the multi-product PUT.
