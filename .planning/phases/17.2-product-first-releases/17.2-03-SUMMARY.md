# Phase 17.2 Plan 03: Product-scoped ticket browser Summary

TicketBrowser gains a `productId` mode that defaults to "All {Product} projects" and posts `{ productId }` to `/api/tickets/search`. Picking one mapped project switches back to project mode with sprints. The add-tickets dialog for an existing release is scoped to the release's product, and a shared NoJiraProjectNotice covers products that have no Jira project.
