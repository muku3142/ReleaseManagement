# Phase 17.2 Plan 09: Hide tickets already in a release Summary

The Tickets page and the add-tickets dialog now have a "Hide tickets already in a release" checkbox, checked by default. While it is checked, every search mode (product, single project, Advanced JQL) sends `hideAlreadyInRelease: true`. The roadmap's Add from Jira browser has no checkbox and sends exactly the same body as before.

## What was built

- `toSearchBody(criteria, releaseId?, hideAlreadyInRelease = false)` adds `hideAlreadyInRelease: true` to every mode's body when the flag is true. It never sends `false`. The bodies built without the flag have not changed.
- `useTicketSearch` now takes `{ criteria, hideAlreadyInRelease }` as its mutation variable, so the flag goes with each search.
- `TicketBrowser` has a new `offerHideReleased` prop. When set, a native checkbox (token classes `text-foreground`, `accent-primary`) appears after the Status fieldset. It is disabled while a search is running. The flag that produced the current result is stored. When that search hid released tickets, both empty-state messages add ", or every match is already in a release".
- `TicketsRoute` and `AddTicketsToReleaseDialog` pass `offerHideReleased`. `roadmap/AddFromJiraDialog.tsx` is unchanged.
