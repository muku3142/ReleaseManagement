## Deviations from Plan

**1. [Rule 1 - Bug] `/brand/*` was forwarded to index.html**
- **Found during:** Task 1. The new `get("/brand/shipflow-mark.svg")` case failed with forwarded URL `/index.html`.
- **Issue:** The plan assumed the controller skips dotted paths. In fact the `[^.]*` guard only constrains the first segment, so `/brand/<file>` matched the `/**` pattern. This is the same defect `assets` had before.
- **Fix:** Added `brand` to the negative lookahead in both mappings, with a comment explaining why. No SPA route starts with `brand`.
- **Files:** `SpaForwardingController.java`
- **Commit:** 67af5f4

**2. Verify commands targeted the main checkout path.** I ran them from this worktree instead.

**3. [Coordinator request] The name lives in one place, and the assets can be regenerated (4d18622)**
- "Shipflow" is taken. `frontend/src/components/brand/brand.ts` now exports `PRODUCT_NAME` and `PRODUCT_TAGLINE`. The visible wordmark (`PRODUCT_NAME.toLowerCase()`) and the tagline in `ShipflowLogo` read from these constants, and so do the tests.
- `ShipflowMark` has no built-in name. Its accessible name is the `title` prop, which callers should pass as `PRODUCT_NAME`.
- I committed `frontend/scripts/brand-assets.py`, overriding the plan's "scratch only" rule. It reads both constants from `brand.ts` and the Nunito/Inter fonts from `node_modules`, then rebuilds the outlined lockup SVGs, their @2x PNGs, `favicon.ico` and `apple-touch-icon.png` from `favicon.svg`.
- When I re-ran it, the PNG and ICO files came out byte-identical. The lockup SVGs changed only in their gradient ids, which no longer contain the name.
- **To rename:**
  1. Edit `brand.ts`.
  2. Run `npm ci` in `frontend/` if `node_modules` is missing.
  3. From the repo root, run `py -I frontend/scripts/brand-assets.py [chrome.exe path]`. It needs Python with Pillow, fontTools and brotli, plus Chrome.
  4. Update the hard-coded occurrences listed below.
