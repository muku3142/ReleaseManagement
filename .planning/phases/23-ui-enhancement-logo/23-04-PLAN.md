| keyboard -> navigation | global key listeners act on user input anywhere in the shell |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-12 | Tampering (XSS) | CommandPalette item labels | mitigate | Render names only as React text children; cmdk value/keywords plain strings; test asserts an `<img onerror>` name creates no element |
| T-23-13 | Tampering | palette navigation | mitigate | Navigate only with typed router params/search built from server ids (UUIDs) through existing validators (`parseRoadmapSearch`, `parseDashboardSearch`); never build URLs from typed text |
| T-23-14 | Elevation of Privilege | data exposure | accept | Palette reuses existing authenticated GET endpoints and is mounted only in the authenticated shell; server-side /api auth remains the control |
| T-23-15 | Denial of Service | eager list fetching | mitigate | `enabled: open` so no list request runs until the palette first opens |
| T-23-16 | Tampering | G-sequences hijacking typing | mitigate | Ignored in form fields/contenteditable, with modifiers, or with an open dialog; no single-key shortcuts |
